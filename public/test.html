Server Connection Test

All players connect through the server, so this test checks the server itself. You need two people, preferably on different networks (for example, home and office).

  1. Both players open this page in a browser and wait for the “Connected to the server” message. The free server may take up to a minute to wake up the first time.
  2. Both players enter the same room code and click “Join”. The first player to join becomes the host.
  3. Once both players appear in the list, click “Stress Test”, then “Copy Report”.
